📦 Seeded Question Database (questions_bank)

Instead of requesting new live topics on every single query (which degrades performance), MockAI incorporates a pre-configured database seeding framework.

  • ✔ 540 Seeded Questions: Fully structured questions database containing specific items for 6 core developer positions (Frontend, Backend, Fullstack, DevOps, Data Engineer, Mobile Developer).
  • ✔ 3 Difficulty Levels: Categorized into Easy, Medium, and Hard configurations.
  • ✔ 3 Interview Styles: Seeding tracks distinct domains (Technical, HR, Behavioral).
  • ✔ Rich Question Models: Supports descriptive text boxes, Multiple Choice Questions (MCQs) containing array choices, and Fill-in-the-Blank (FIB) keyword schemas.

Dynamic Generative AI Evaluation Engine

MockAI leverages Google Gemini's API to construct high-precision JSON scorecards. The scoring framework runs structured prompt schemas configured to return detailed analytics.

Correctness

Measures factual precision, technical terms, and correct logic.

Clarity

Measures grammar, structuring, readability, and sentence flow.

Relevance

Measures how accurately the reply answers specific constraints.

🚀 Hybrid Fallback Engine: Incorporates a local scoring module that performs offline evaluations when the API key is not configured by matching keywords (FIB), validating option keys (MCQs), and analyzing word lengths (Descriptive).

Premium Live Interview Room Experience

The frontend adapts UI elements to fit the specific question type retrieved from the question database.

  • ✔ Tailored Inputs: Replaces the descriptive textarea box with 4 selectable choice cards during MCQs, and uses compact inputs for Fill-in-the-Blank questions.
  • ✔ Interactive Word Suggestion: Prompts the user with word targets based on difficulty (e.g. min 25 words for Easy, min 50 for Hard descriptive questions).
  • ✔ State Resumption: Saves each submission in real-time, allowing users to safely pause sessions and resume from the dashboard timeline.
  • ✔ Skeleton Loaders: Renders modern loading states to prevent page freezes during backend GenAI evaluation loops.
